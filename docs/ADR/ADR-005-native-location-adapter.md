# ADR-005: Native location adapter

Accepted. All providers implement the location contract. Web and synthetic providers support development; iOS Core Location and Android foreground-service implementations support production. Location processing never depends on render frequency.

2026-09-13 implementation: the Android test app uses a Capacitor bridge to an Android location foreground service. Android's LocationManager GPS/network providers, monotonic active clock, filtering and transactional SQLite writes are owned natively; the WebView polls a read-only state/delta mirror. Actions originate from visible app controls or the recording notification. No background-location permission is requested. Process recovery restores the last checkpoint paused rather than inventing capture during downtime. The bridge has a synthetic test double; physical screen-off/device qualification is still required. This is not yet a production reliability claim.

2026-09-28 iOS 0.2.19 (24): use Capacitor Geolocation/Core Location through the existing LocationProvider contract, including recovered-run resume. Preview starts on the run screen when permission is already granted; otherwise show the location explanation. Async permission and watch callbacks are invalidated after stop. iOS recording remains foreground-only and uses the existing IndexedDB/checkpoint pipeline.

Superseding user authorization on 2026-09-28 for iOS 0.2.20 (25): after seeing the missing offline-map notice, the user approved downloading nearby map areas from OpenStreetMap Overpass services. Native HTTP now fetches public geography from overpass-api.de and overpass.private.coffee; requests disclose the approximate area but do not upload activity records. iOS caches downloaded neighborhoods in IndexedDB and uses the same transport for live, replay and preview maps. This supersedes the earlier local-only choice in 0.2.19. Android retains its existing native cache.

Validation: 293 automated tests pass; TypeScript, web/mobile builds, and signed iPhone compilation pass. Physical iPhone GPS/map/replay acceptance remains pending. The previously supplied private 2026-09-22 replay file is no longer available at its attachment path; its opt-in regression was skipped. Replay timing, camera and renderer code were not modified.
